#Ventas_Tech_BD
Es una base de datos desarrollada para la practica de SQL

##Motor utilizado
SQL Server

### Instrucciones de ejecucion
1. Ejecutar el script completo
2. El script crea la base de datos 'Ventas_Tech_BD', sus tablas y las relaciones entre ellas
3. Luego carga los datos iniciales
4. Finalmente se ejecutan las consultas de verificacion para comprobar la carga de datos.

## Comentarios
Se agrega archivo m4_consultas_negocios para ejecutar el ejercicio m5_consultas_joins; considerar el archivo Ventas_Tech_BD como m3
